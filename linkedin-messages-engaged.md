# LinkedIn outreach — the four who engaged but never replied

Everyone here has opened repeatedly. None have replied. Email has done what it can with
them, so the point of switching channel is to be a person rather than another message in
a thread they're already ignoring.

**Premium Business budget:** ~15 InMails/month. Four is affordable.

**Voice notes require a 1st-degree connection and the mobile app.** You cannot voice-note
a stranger. So: connection request first, voice note after they accept. InMail works
without connecting, but text and attachments only.

**Character limits:** connection request note = 300 characters. InMail = 200 char subject,
1900 char body. All drafts below are well inside.

## Order of operations

1. Send all four connection requests in one sitting.
2. Vincent's can go as a direct message now if you're already connected.
3. Wait for accepts. Do not follow up on a pending request.
4. Once accepted, send the follow-up text.
5. Voice note only after that, and only if the conversation is already going. A voice note
   into silence is heavier than a text into silence.
