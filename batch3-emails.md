# Batch 3 — the 50 first emails

Assembled 4 Aug 2026 against `EMAIL Copywriting/email-copywriting.md`.

Every email is: opener + reaction + emoji, then the reason and credibility anchor, then one
question. Openers 1-17 were drafted before the emoji set changed and have been converted to
🫡 🤩 😲 🤯.

**Standard block appended to every opener:**

> Real reason I'm writing: you're hiring your first GTM person and I'd like to be it. I run
> outbound for my own startup, and I'm about to start doing the same for a Swiss AI company.
>
> Before anything else though, a real question: {QUESTION}

**A/B:** odd rows get Subject A `{First} from one outbound nerd`. Even rows get Subject B
`{First}, your first GTM`. 25 and 25.
